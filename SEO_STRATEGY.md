# Daily Utility Hub — SEO Strategy

## Goal
Acquire high-intent organic traffic from users searching for a specific utility, while building a recognizable toolbox brand.

## Core SEO Model
Every important tool has one primary canonical page with a descriptive slug, useful content, fast interaction, and strong internal linking.

Examples:
- `/tools/image-compressor`
- `/tools/merge-pdf`
- `/tools/gst-calculator`
- `/tools/attendance-calculator`

## Search Intent Groups
### Transactional utility intent
Examples: compress image, merge PDF, QR generator.

The interactive tool must appear quickly; do not bury it below long SEO text.

### Calculation intent
Examples: GST calculator, EMI calculator, attendance calculator.

Provide immediate calculator + concise formula/explanation.

### Long-tail intent
Future examples:
- compress image to 50kb
- passport photo image resizer
- home loan EMI calculator

Do not create hundreds of near-duplicate pages automatically. A long-tail page must provide distinct intent-specific value and use a deliberate canonical/indexing strategy.

## On-Page Requirements
Each tool page:
- unique title;
- unique meta description;
- single descriptive H1;
- concise intro;
- interactive tool near top;
- how-to section;
- relevant explanation;
- FAQ where useful;
- related tools;
- breadcrumbs;
- canonical URL.

## Technical SEO
- XML sitemap.
- robots.txt.
- canonical production domain.
- clean status codes.
- no broken internal links.
- semantic HTML.
- mobile responsive.
- good Core Web Vitals.
- Open Graph metadata.
- structured data only when it accurately matches visible page content.

## Internal Linking
Link between:
- tool -> related tools;
- category -> tools;
- homepage -> popular categories/tools;
- tool -> parent category;
- informational content -> relevant tools where appropriate.

Avoid excessive keyword-stuffed footer links.

## Content Quality
Do not generate filler paragraphs solely to increase word count. Tool pages should answer:
- What does this tool do?
- How do I use it?
- What happens to my file/data?
- What should I know about the result?
- What related task might I need next?

## India + Global Strategy
The core site remains global. India-specific calculators/content may explicitly target Indian context where the calculation itself is country-specific, such as GST.

Do not place "India" across unrelated global tool titles just for ranking.

## Search Console Launch Checklist
After production domain is connected:
- verify domain/property;
- submit sitemap;
- inspect primary pages;
- monitor indexing;
- review queries/pages;
- identify impressions with low CTR;
- identify new long-tail tool opportunities from real data.

## Programmatic SEO Guardrail
Do not publish mass-generated variants until the main site has demonstrated demand. Future template-driven pages require:
- distinct search intent;
- useful page-specific settings/content;
- canonical strategy;
- quality review;
- no doorway-page behavior.
